# Kategorien und Tags

## Kategorien

Der Reiter **Kategorien** zeigt den Kategoriebaum. **Neue Kategorie** legt eine Kategorie auf der obersten Ebene an, **Unterkategorie** in der Zeile eine darunter. Jede Kategorie hat:

- **Name** und **Adresse (Slug)** für Filter-Links; leer: aus dem Namen gebildet.
- **Unterhalb von**: die übergeordnete Kategorie. Eine Kategorie kann nicht unter sich selbst oder einer eigenen Unterkategorie stehen.
- **Beschreibung**: steht über der Liste, wenn nach der Kategorie gefiltert wird.
- **Sichtbar**: sonst sieht nur der Admin die Kategorie. Eine verborgene Kategorie verbirgt auch ihre Unterkategorien, im Filter und in den Formularen der Besucher.

Die Pfeile ▲ ▼ ändern die Reihenfolge unter Geschwistern. Ein Eintrag kann in mehreren Kategorien stehen. Wer nach einer Kategorie filtert, sieht auch die Einträge ihrer Unterkategorien. Beim Löschen rücken Unterkategorien eine Ebene nach oben; die Einträge verlieren nur diese Kategorie.

## Tags

Unter den Kategorien stehen die Tags mit der Zahl ihrer Einträge. Wie Tags entstehen, regelt **Einstellungen → Tags**:

| Einstellung | Bedeutung |
|---|---|
| Aus | Keine Tags auf der Website und in den Formularen der Besucher |
| An, Inhaber wählen aus den vorhandenen Tags | Der Admin legt Tags an (im Formular eines Eintrags), Inhaber haken sie an |
| An, Inhaber dürfen neue Tags anlegen | Inhaber tippen Tags durch Kommas getrennt ein |

Ein Tag lässt sich in der Tabelle umbenennen. **Zusammenführen**: Wer ein Tag in den Namen eines anderen umbenennt, führt beide zusammen. Die Einträge des alten Tags bekommen das andere, das alte verschwindet. Groß- und Kleinschreibung zählen dabei nicht; der Name des bestehenden Tags bleibt.

## Suche und Filter

Mit **Suche und Filter über der Liste zeigen** steht über der Liste ein Formular:

- **Suche**: Wörter in Titel und öffentlichen Textfeldern (auch formatiertem Text und Auswahlfeldern). Alle Wörter müssen vorkommen.
- **Kategorie** und **Tag**: nur sichtbare.
- Jedes Feld mit **Als Filter über der Liste anbieten**.

Kategorien und Tags an den Einträgen sind Links auf die so gefilterte Liste. Die Filter bleiben beim Blättern erhalten.
