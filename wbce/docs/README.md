# Listings – Dokumentation

`Listings` ist ein Seitenmodul für WBCE 1.7: Verzeichnisse von Einträgen mit eigenen Feldern, die Besucher selbst anlegen und pflegen können, mit Freigabe durch den Admin. Beispiele sind Mitgliederlisten, Kleinanzeigen, Jobbörsen, Branchenbücher oder ein Addon-Repository. Diese Seiten beschreiben die Bedienung für Redakteure und Administratoren.

## Auf einen Blick

- Ein Abschnitt vom Typ **Listings** ist ein **Verzeichnis**: genau ein Feldsatz, beliebig viele Einträge, eigene Einstellungen. Mehrere Verzeichnisse auf einer Seite stören sich nicht.
- Oben stehen die Reiter **Einträge**, **Felder**, **Kategorien**, **Layouts** und **Einstellungen**, rechts daneben **Hilfe** und die Hauptaktion des Reiters.
- Ein Eintrag ist auf der Website sichtbar, wenn er **veröffentlicht** und nicht abgelaufen ist. Diese Regel gilt überall: Liste, Detailseite, RSS, Suche und Bilder.
- Ein neues Verzeichnis beginnt am schnellsten mit einer [Vorlage](Vorlagen-und-Import.md): **Felder → Mit einer Vorlage beginnen**.

## Erste Schritte

1. Eine Seite anlegen und einen Abschnitt vom Typ **Listings** hinzufügen.
2. Unter **Felder** eine Vorlage laden oder Felder selbst anlegen.
3. Unter **Einstellungen** festlegen, ob Besucher Einträge anlegen dürfen, ob sie dafür ein Konto brauchen, ob der Admin freigibt und wie lange Einträge laufen.
4. Unter **Einträge** eigene Einträge anlegen und Einträge von Besuchern freigeben oder ablehnen.
